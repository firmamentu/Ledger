# Ledger

安装时记账，卸载时对账。Ledger 是一个只在本机工作的 macOS 知情工具：新 App 落盘时记录它留下了什么，App 消失后再把账本摊开——还剩什么、每一样是什么、能不能动。

开发状态：**M1–M7 全部完成**（基线扫描、安装记账、卸载检测、残留清单与清理、周报、设置页）。验收记录见 docs/05-acceptance.md。

## 构建

要求 macOS 14+、Swift 5.9+ 与 Xcode 26（构建脚本自动使用已安装的 Xcode 工具链）。

```sh
./scripts/build-app.sh
open build/Ledger.app
```

构建产物为 `build/Ledger.app`，ad-hoc 签名。

## 运行

Ledger 是菜单栏应用，启动时不显示窗口：

- 左键点击菜单栏书本图标：打开主窗口；有待处理项时图标旁显示红点。
- 右键点击：打开 Ledger / 暂停记录 / 退出 Ledger。
- 关闭窗口不会退出应用。

四个页签：

- **概览**：已记录 App 数 / 未知项 / 今日新增；App 足迹列表（状态徽标、行菜单：查看清单、重新追踪）；「添加 App」手动登记已装的 App（识别轨，尽力而为）。
- **待处理**：已卸载/安装未完成的 App（残留降序）；「只是移动了它？」撤销入口；「历史」分段 = 操作痕迹时间线 + 清理报告列表。
- **周报**：本周新增堆叠柱状图（按 App/按类别）、Top5、今日明细、导出 Markdown。
- **设置**：扫描根勾选、权限状态（FDA）、保留策略（30 天/500MB）、通知开关、暂停记录、登录自启。

## 清理流程

待处理 → 点击 App → 残留清单（四组核对：可删/已变化/已消失/需管理员；verdict 与 requires_admin 分开展示；推断项默认不勾选）→ 勾选 → 移入废纸篓（可从废纸篓还原）→ 报告（删了什么/留了什么/怎么恢复，导出 `reports/` 目录）。系统项（注册项/管理员权限项）只给出处理命令，不代执行。

## 数据

本地账本位于：

```text
~/Library/Application Support/com.ledger.app/ledger.sqlite
```

使用 SQLite WAL 模式，`PRAGMA user_version = 1`。数据不加密（依赖 FileVault），不联网，无遥测。

## 权限

- 无额外权限即可运行：常规目录扫描、用户级移废纸篓。
- Full Disk Access（可选）：补全 TCC 保护目录的盲区；未授权时盲区如实标注。
- 系统通知（可选）：卸载时提示「还有 N 处」；未授权仅菜单栏红点。

## 已知限制

- 只对「记账过的 App」完整；更早安装的 App 走「添加 App」识别轨（尽力而为）。
- 睡眠唤醒对账为节流全量重扫；部分系统目录存在 readdir 阻塞（已超时保护并标注盲区）。
- 详情见 docs/（需求、架构、设计、流程、验收）与 devlog/（每日进度）。
